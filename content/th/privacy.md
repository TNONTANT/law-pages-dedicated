## 4. การเปิดเผยข้อมูลต่อบุคคลที่สาม

**ข้อผูกพันด้านการตลาด:** เรา**ไม่ขาย แลกเปลี่ยน หรือให้เช่า**ข้อมูลส่วนบุคคลของคุณ; **ไม่ใช้**ข้อมูลของคุณเพื่อการโฆษณาของบุคคลภายนอก, retargeting, หรือการจัดทำโปรไฟล์เพื่อโฆษณา; **ไม่อนุญาต**ให้ Sub-processor ใดนำข้อมูลของคุณไปฝึก AI model ของตนเอง การเพิ่ม Sub-processor เพื่อวัตถุประสงค์ข้างต้นจะถือเป็นการขยายขอบเขตและต้องขอความยินยอมใหม่ (ดู §9)

เราเปิดเผยข้อมูลเฉพาะกับ Sub-processor ตามรายชื่อใน [/th/subprocessors/](/th/subprocessors/) สรุป:

| ผู้ให้บริการ | ข้อมูลที่ส่ง | วัตถุประสงค์ | ที่ตั้ง | สัญญาคุ้มครอง |
|------------|-------------|-------------|--------|--------------|
| **Google LLC** (Gemini API — แบบเสียค่าใช้จ่าย) | รูปถ่ายอาหาร, คำสั่ง AI | วิเคราะห์โภชนาการด้วย AI | **ทั่วโลก** — Google ส่ง request ไปยังภูมิภาคใดก็ได้; ไม่สามารถเลือกได้ | Google APIs ToS + Gemini API Additional Terms; คำมั่นไม่นำไปฝึก AI (สำหรับแบบเสียค่าใช้จ่าย) |
| **Google LLC** (Cloud Storage) | รูปถ่ายอาหาร (ชั่วคราว) | Buffer เก็บรูป 14 วัน | กรุงเทพฯ (asia-southeast3) | Google Cloud Platform Terms + DPST |
| **Google LLC** (Cloud Run + Cloud Logging) | ข้อมูล request ระหว่างประมวลผล, log ระบบ (ไม่มีเนื้อหารูปอาหาร) | ประมวลผล backend + log ปฏิบัติการ | กรุงเทพฯ (asia-southeast3) | Google Cloud Platform Terms |
| **Neon Inc.** | ข้อมูลผู้ใช้ทั้งหมด | ฐานข้อมูลหลัก (Neon Postgres แพ็คเกจ Launch) | สิงคโปร์ (AWS ap-southeast-1) | [Neon DPA](https://neon.com/dpa) + [รายชื่อ sub-processor ของ Neon](https://neon.com/subprocessors) |
| **LINE Corporation** | LINE User ID, ชื่อที่แสดง, ข้อความ | ยืนยันตัวตน + ส่ง notification | ญี่ปุ่น/สิงคโปร์ | LINE ToS + Messaging API Terms + LINE Login Terms |

> Google LLC ให้คำมั่นว่า prompt และผลลัพธ์ที่ลูกค้าส่งผ่าน Gemini API **แบบเสียค่าใช้จ่าย** จะไม่ถูกนำไปใช้ฝึก AI model ของ Google เราไม่ใช้ Gemini แบบฟรีสำหรับ SnapCal

## 5. การส่งข้อมูลไปยังต่างประเทศ (ม.28)

การส่งข้อมูลต่อไปนี้ออกนอกประเทศไทย การประมวลผลในประเทศ (Cloud Run, GCS staging, Cloud Logging — ทั้งหมดในกรุงเทพฯ asia-southeast3) ไม่อยู่ภายใต้ ม.28

- **Google LLC (Gemini API — global routing):** รูปอาหารของคุณอาจถูกประมวลผลโดย Google ในภูมิภาค Google Cloud ใดก็ได้ทั่วโลก Gemini Developer API ไม่อนุญาตให้เลือกภูมิภาค มาตรการคุ้มครอง: Google APIs Terms of Service, Gemini API Additional Terms, และคำมั่นว่าข้อมูลลูกค้าแบบเสียค่าใช้จ่ายจะไม่ถูกนำไปฝึก model
- **Neon Inc. (สิงคโปร์ — AWS ap-southeast-1):** ครอบคลุมโดย Singapore PDPA 2012 ซึ่งโดยทั่วไปได้รับการยอมรับว่ามีมาตรฐานเทียบเท่า Thai PDPA ครอบคลุมเพิ่มเติมโดย Neon Data Processing Addendum
- **LINE Corporation (ญี่ปุ่น / สิงคโปร์):** ครอบคลุมโดย Japan APPI และ Singapore PDPA ภายใต้ LINE Terms และ LINE Messaging API / LINE Login terms

จนกว่า PDPC ของไทยจะประกาศรายชื่อประเทศที่มีมาตรฐานเทียบเท่าตาม ม.28 อย่างเป็นทางการ เราอาศัย **ความยินยอมชัดแจ้ง** (ม.24(1) สำหรับข้อมูลทั่วไป, ม.26 สำหรับข้อมูลสุขภาพอ่อนไหว) ร่วมกับสัญญาคุ้มครองข้างต้น

## 7. ผลกระทบหากไม่ให้ข้อมูล

- **ไม่ยินยอม cross-border:** ไม่สามารถใช้งาน SnapCal ได้ เนื่องจากการวิเคราะห์รูปอาหารต้องส่งรูปไปยัง Gemini API ของ Google ซึ่งอาจประมวลผลในภูมิภาค Google ใดก็ได้ทั่วโลก
- **ไม่ยินยอมข้อมูลสุขภาพ:** ไม่สามารถดูสรุปโภชนาการส่วนตัวหรือคำนวณ TDEE ได้ แต่ยังสามารถส่งรูปอาหารเพื่อดูค่าประมาณทั่วไปได้

---

## 8. ความปลอดภัยของข้อมูล

- การเชื่อมต่อทั้งหมดเข้ารหัสด้วย TLS 1.2+
- ฐานข้อมูล Neon เข้ารหัสขณะพัก (AES-256)
- Backend compute, photo staging, และ log ปฏิบัติการ ตั้งอยู่ใน Google Cloud Bangkok (asia-southeast3) — ข้อมูลของส่วนเหล่านี้อยู่ในประเทศไทย
- การเข้าถึงข้อมูลจำกัดเฉพาะผู้ดำเนินการผ่าน IAM
- ไม่มีการเก็บรหัสผ่านหรือข้อมูลบัตรเครดิต

หากเกิดการละเมิดข้อมูลที่อาจเกิดความเสี่ยงต่อสิทธิ์ของคุณ เราจะแจ้ง PDPC ภายใน 72 ชั่วโมง และแจ้งคุณโดยเร็วที่สุด (ม.37(4))

## 9. การเปลี่ยนแปลงนโยบาย

เราอาจอัพเดทนโยบายนี้เป็นครั้งคราว หากมีการเปลี่ยนแปลงที่กระทบสิทธิ์ของคุณอย่างมีนัยสำคัญ เราจะแจ้งผ่าน LINE ล่วงหน้าอย่างน้อย 30 วัน การใช้บริการต่อเนื่องหลังวันที่มีผลบังคับถือว่าคุณรับทราบการเปลี่ยนแปลง

**การเปลี่ยนแปลงที่เป็นสาระสำคัญ** (ประเทศปลายทางใหม่ ข้อมูลอ่อนไหวประเภทใหม่ หรือเปลี่ยนฐานกฎหมาย) จะต้องมีการ **ขอความยินยอมใหม่** — คุณจะได้รับการขอให้ทบทวนและยอมรับเงื่อนไขที่ปรับปรุงก่อนใช้บริการต่อ บันทึกความยินยอมเดิมยังคงเป็นหลักฐานที่ใช้ได้สำหรับการประมวลผลที่เกิดขึ้นก่อนการเปลี่ยนแปลง

**ปรับปรุงเอกสาร (2026-06-28) — ไม่กระทบขอบเขต:** เพิ่มข้อผูกพันด้านการตลาดอย่างชัดเจนใน §4 (ห้ามใช้เพื่อโฆษณาบุคคลภายนอก/profiling/ฝึก AI ของบุคคลภายนอก); ปรับข้อความบน LIFF consent surface ให้กระชับและเชื่อมโยงไปยัง [รายชื่อ Sub-processor](/th/subprocessors/) แทนการระบุชื่อ vendor ในหน้าความยินยอม สรุป: ผู้ประมวลผล วัตถุประสงค์ และระยะเวลาเก็บข้อมูลไม่เปลี่ยน — **ไม่ต้องขอความยินยอมใหม่** (consent version คงเป็น 2026-06-07-v2)

**v2 (2026-06-07):** เปลี่ยนผู้ให้บริการฐานข้อมูลจาก Supabase Inc. เป็น Neon Inc. (ภูมิภาคเดิม สิงคโปร์) เปลี่ยนวิธีประมวลผล AI จาก Vertex AI (สิงคโปร์ regional) เป็น Gemini Developer API (global routing) ย้าย backend compute และ photo staging ไปยัง Google Cloud Bangkok (asia-southeast3) ผู้ใช้เดิมต้องยินยอมใหม่ก่อน hard-block re-consent gate
