หน้านี้แสดงรายชื่อบุคคลที่สาม (ผู้ประมวลผลข้อมูลส่วนบุคคล ตาม PDPA ม.40) ซึ่งประมวลผลข้อมูลผู้ใช้ SnapCal แทนเรา เราจะอัพเดทหน้านี้เมื่อมีการเปลี่ยนแปลง การเปลี่ยนแปลงที่สำคัญ (เช่น ผู้ประมวลผลรายใหม่ที่จัดการข้อมูลอ่อนไหว หรือประเทศปลายทางใหม่) จะมีการแจ้งล่วงหน้า 30 วันผ่านแอป ตาม [นโยบายความเป็นส่วนตัว](/th/privacy/) §9

**อัพเดทล่าสุด:** 2026-06-28

---

## ข้อผูกพันด้านการตลาด

ผู้ประมวลผลที่ระบุในหน้านี้**ไม่มีรายใด**ถูกใช้เพื่อ:

- การโฆษณาหรือ retargeting ของบุคคลภายนอก
- การจัดทำโปรไฟล์เพื่อโฆษณา (advertising profiling)
- การขาย, แลกเปลี่ยน, หรือให้เช่าข้อมูลส่วนบุคคล
- การฝึก AI model ของบุคคลภายนอกด้วยข้อมูลของคุณ

หากมีการเพิ่มผู้ประมวลผลใหม่เพื่อวัตถุประสงค์ใดข้างต้น จะถือเป็นการขยายขอบเขตการประมวลผล (scope of consent เปลี่ยน) และต้องขอความยินยอมใหม่ตาม PDPA ม.19 ก่อนเริ่มใช้งาน

## สรุปการส่งข้อมูลข้ามประเทศ (PDPA ม.28)

| การส่งข้อมูล | ประเทศปลายทาง | กลไกคุ้มครอง |
|--------------|----------------|----------------|
| รูปอาหาร → Gemini API | ทั่วโลก (ภูมิภาค Google ใดก็ได้) | ความยินยอมชัดแจ้ง + Google API Terms (คำมั่นไม่นำไปฝึก AI สำหรับแบบเสียค่าใช้จ่าย) |
| ข้อมูลผู้ใช้ → Neon | สิงคโปร์ | ความยินยอมชัดแจ้ง + Neon DPA + Singapore PDPA 2012 (มีมาตรฐานคุ้มครองเทียบเท่า) |
| ข้อความ LINE → LINE Corp | ญี่ปุ่น / สิงคโปร์ | ความยินยอมชัดแจ้ง + LINE Terms + Japan APPI / Singapore PDPA |

การส่งข้อมูลอื่นๆ (GCS staging, Cloud Run compute, Cloud Logging) เป็นการประมวลผลในประเทศ — ข้อมูลไม่ออกนอกประเทศไทย

## ผู้ประมวลผลที่จัดการข้อมูลอ่อนไหว (PDPA ม.26)

ข้อมูลอ่อนไหวตาม ม.26 ในบริบท SnapCal = ข้อมูลสุขภาพ (น้ำหนัก, ส่วนสูง, เพศ, อายุ, ระดับกิจกรรม, เป้าหมายแคลอรี, ค่า TDEE ที่คำนวณ)

| ผู้ประมวลผล | เข้าถึงข้อมูลสุขภาพ ม.26? | หมายเหตุ |
|--------------|----------------------------|------------|
| **Neon Inc.** | ✅ ใช่ — จัดเก็บโปรไฟล์สุขภาพทั้งหมด | ฐานข้อมูลหลัก; ลบทันทีเมื่อถอนความยินยอม (ไม่มีฐานกฎหมายสำรอง) |
| **Google LLC** (Gemini API) | ❌ ไม่ — เห็นเฉพาะรูปอาหาร ไม่ได้รับโปรไฟล์สุขภาพ | request ที่ส่งให้ Gemini มีเฉพาะรูปและคำสั่งวิเคราะห์โภชนาการ |
| **Google LLC** (Cloud Storage) | ❌ ไม่ — เก็บเฉพาะรูปอาหารชั่วคราว | buffer 14 วัน; ไม่มีโปรไฟล์สุขภาพ |
| **Google LLC** (Cloud Run + Logging) | ❌ ไม่ — log ระบบ ไม่บันทึกค่าโปรไฟล์ | log ระดับ request/response metadata เท่านั้น |
| **LINE Corporation** | ❌ ไม่ — เห็นเฉพาะข้อความใน chat | userId + ข้อความที่ user ส่งเอง; ไม่เห็นโปรไฟล์ในแอป |

การยินยอมตาม ม.26 จึงผูกกับ **Neon Inc. (สิงคโปร์)** เป็นหลัก — การเปลี่ยนผู้ประมวลผลฐานข้อมูลรายนี้เป็นเหตุที่ต้องขอความยินยอม ม.26 ใหม่

## หมายเหตุ

- "Sub-processor" หมายถึงบุคคลที่สามที่เราว่าจ้างให้ประมวลผลข้อมูลส่วนบุคคลแทนเรา ต่างจาก "Controller" แยก (เช่น LINE Corporation เป็น joint controller สำหรับบางการประมวลผลภายใต้ข้อกำหนดของ LINE เอง)
- รายชื่อนี้สะท้อนสถานะ ณ วันที่ระบุข้างบน เราเป็น beta ระยะแรก — รายการอาจเพิ่มขึ้นตามการเติบโตของผลิตภัณฑ์
- คำถามหรือข้อคัดค้านต่อ sub-processor ใด: <a href="mailto:privacy@snapcal.app">privacy@snapcal.app</a>
